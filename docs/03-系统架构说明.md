## 四、核心流程：MQTT 告警链路

```
MQTTX (设备模拟)
    │
    │ publish: device/fall/event
    │ payload: {"deviceId":"FALL-001","type":"FALL",...}
    ▼
EMQX Broker (broker.emqx.io:1883)
    │
    │ subscribe: device/fall/#
    ▼
后端 MqttSubscriber.messageArrived()
    │
    │ 1. 解析 deviceId
    │ 2. deviceMapper 查询 → resident_id
    │ 3. residentMapper 查询 → 老人姓名
    │ 4. alarmMapper.insert() → 写入告警
    ▼
MySQL alarm 表
    │
    │ GET /api/alarms
    ▼
Web 后台告警列表 → 管理员处理 → PUT /api/alarms/{id}/handle
```

## 五、安全设计

- **密码加密**：BCrypt（Spring Security 默认）
- **鉴权方式**：JWT Token，Authorization: Bearer <token>
- **Token 有效期**：24 小时（86400000ms）
- **CORS**：允许所有来源，前后端分离必备
- **CSRF**：已禁用（前后端分离 + JWT 不需要）
