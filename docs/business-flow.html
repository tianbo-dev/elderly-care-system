🏥 乐康养老系统 - 业务流程图

乐康养老系统实训项目核心业务流程可视化

📝 3.1 登录注册流程

用户打开登录页 → 判断是否已有账号 → 登录验证或注册 → 获取 JWT Token → 进入系统

flowchart TD A[用户打开登录页] --> B{已有账号?} B -->|是| C[输入账号密码] B -->|否| D[跳转注册页] D --> E[填写注册信息] E --> F[注册成功 自动登录] C --> G[后端验证账号密码] G --> H{验证通过?} H -->|是| I[返回 JWT Token] H -->|否| J[提示账号或密码错误] I --> K[前端存储 Token] K --> L[进入系统主页]

📋 3.2 入住登记 CRUD 流程

管理员登录后台 → 入住管理页面 → 执行增删改查操作 → 数据库更新 → 前端列表刷新

flowchart TD A[管理员登录后台] --> B[入住管理页面] B --> C{操作类型} C -->|新增| D[填写老人信息表单] C -->|查询| E[列表展示/搜索] C -->|修改| F[编辑表单] C -->|删除| G[确认删除] D --> H[提交到后端] F --> H G --> I[软删除标记 deleted=1] H --> J[数据库增/改] I --> J E --> K[后端分页查询] J --> L[返回结果] K --> L L --> M[前端更新列表]

⚠️ 3.3 跌倒告警流程（核心）

老人跌倒 → 设备检测 → MQTTX 模拟上报 → Broker 转发 → 后端订阅 → 关联老人 → 写入告警 → 后台展示 → 管理员处理

flowchart TD A[老人跌倒] --> B[设备传感器检测] B --> C[MQTTX 客户端发布消息] C --> D[MQTT Broker broker.emqx.io:1883] D --> E[后端 MqttSubscriber 订阅接收] E --> F[解析 payload 中的 deviceId] F --> G[查询 device 表得到 resident_id] G --> H[查询 resident 表得到老人姓名] H --> I[写入 alarm 告警表] I --> J[Web 后台告警列表展示] J --> K[管理员点击处理] K --> L[更新 alarm 状态为已处理] L --> M[记录处理人和备注]
