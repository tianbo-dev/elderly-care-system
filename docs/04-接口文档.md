# 乐康养老系统 - 接口文档

> Base URL: `http://localhost:8080/api`
> 鉴权方式：除 `/auth/**` 外，所有请求需在 Header 携带 `Authorization: Bearer <token>`

---

## 一、认证接口

### 1.1 登录

- **URL**: `POST /auth/login`
- **请求体**:
```json
{
  "username": "admin",
  "password": "123456"
}
```
- **响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": 1,
    "username": "admin",
    "role": "ADMIN"
  }
}
```

### 1.2 注册

- **URL**: `POST /auth/register`
- **请求体**:
```json
{
  "username": "family02",
  "password": "123456",
  "phone": "13900139005",
  "role": "FAMILY"
}
```
- **响应**:
```json
{
  "code": 200,
  "message": "success"
}
```

```json
{

  "data": {
    "records": [
      {
        "id": 1,
        "name": "张建国",
        "gender": 1,
        "age": 78,

        "residentStatus": 1

    ],
    "total": 3,

```

### 2.2 新增老人

```json
{
```

## 三、告警管理接口

### 3.1 分页查询告警

- **URL**: `GET /alarms`
- **参数**:
  | 参数 | 类型 | 默认值 | 说明 |
  |------|------|--------|------|
  | pageNum | int | 1 | 页码 |
  | pageSize | int | 10 | 每页条数 |
  | status | int | - | 0待处理 / 1已处理 |
- **响应**:
```json
{
  "code": 200,
  "data": {
    "records": [
      {
        "id": 4,
        "deviceId": "FALL-001",
        "residentId": 1,
        "residentName": "张建国",
        "alarmType": "FALL",
        "alarmTime": "2026-09-09T22:48:16",
        "status": 0,
        "handleTime": null,
        "handleBy": null,
        "handleRemark": null
      }
    ],
    "total": 4
  }
}
```

### 3.2 查询待处理告警数

- **URL**: `GET /alarms/unhandled-count`
- **响应**:
```json
{
  "code": 200,
  "data": 3
}
```

### 3.3 处理告警

- **URL**: `POST /alarms/{id}/handle`
- **请求体**:
```json
{
  "handleBy": "admin",
  "handleRemark": "老人轻微擦伤，已检查确认"
}
```
- **响应**:
```json
{
  "code": 200,
  "message": "success"
}
```

## 四、MQTT 消息规范

### 4.1 跌倒告警消息

- **Topic**: `device/fall/event`
- **QoS**: 1
- **Payload (JSON)**:
```json
{
  "deviceId": "FALL-001",
  "type": "FALL",
  "timestamp": 1788964481207,
  "location": "房间内",
  "severity": "HIGH"
}
```
- **字段说明**:
  | 字段 | 说明 |
  |------|------|
  | deviceId | 设备编号，需在 device 表中存在 |
  | type | 告警类型，默认 FALL |
  | timestamp | 事件时间戳（毫秒） |
  | location | 跌倒位置 |
  | severity | 严重程度 |

### 4.2 订阅 Topic

- 后端订阅: `device/fall/#`
- Broker: `tcp://broker.emqx.io:1883`
- 用户名/密码: `public` / `public`

## 五、通用响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| code | 说明 |
|------|------|
| 200 | 成功 |
| 401 | 未授权（Token 无效/过期） |
| 500 | 服务器错误 |
